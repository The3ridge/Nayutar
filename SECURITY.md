# Security policy

## Supported versions

Nayutar is pre-release. There are no released versions and nothing is supported
except the current `main` branch.

## Reporting a vulnerability

This repository is currently private. If you have access, report a vulnerability
privately and directly to the maintainer, `@Kaikei-e`. Do not open an issue or a
public discussion for it.

Once the repository is public, the intended channel is GitHub's private
vulnerability reporting: open the Security tab and choose "Report a
vulnerability". The maintainer has to enable that feature in the repository
settings first.

This is a personal project. Reports are handled on a best-effort basis, and there
is no guaranteed response or fix timeline.
